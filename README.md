# Centro de Formación Somorrostro · La Cantera Tecnológica

> **«Tu futuro empieza aquí · *Zure etorkizuna hemen hasten da*»**  
> Rediseño web moderno, responsive y de alto rendimiento para el **Centro de Formación Somorrostro** (San Juan 10, Muskiz, Bizkaia).

---

## 🚀 Sobre el Proyecto: Ruta A (La Cantera Tecnológica)

Este proyecto plasma una visión innovadora y motivadora del Centro de Formación Somorrostro como el gran vivero y cantera de talento tecnológico de Bizkaia y Euskadi. Inspirado en su identidad oficial ([somorrostro.com](https://www.somorrostro.com)), el diseño rompe con los esquemas educativos tradicionales para centrarse en:

* **Metodología ETHAZI (Aprendizaje Basado en Retos Colaborativos)**: Sin exámenes memorísticos estériles; resolución de desafíos reales planteados por el entorno productivo e industrial de Bizkaia.
* **Espíritu de Equipo y Compañerismo**: *«Aquí nadie se queda atrás»*, mentoring entre iguales y acompañamiento tutorial cercano.
* **Campus de +75.000 m² en San Juan 10 (Muskiz)**: Espacios formativos de vanguardia (Edificios *Lanberri* y *Suberri*) en un entorno natural conectado por Renfe Cercanías (Línea C2) y Bizkaibus.

---

## 🛠️ Talleres de Informática y Comunicaciones

1. **Taller de Montaje y Mantenimiento de Hardware (`SMR`)**
   * Grado Medio en Sistemas Microinformáticos y Redes.
   * Bancos de trabajo antiestáticos (ESD), arquitectura física, osciloscopios, diagnóstico de componentes y ensamblaje de estaciones de trabajo y servidores rack.
2. **Laboratorio de Redes, Servidores y Ciberseguridad (`ASIR`)**
   * Grado Superior en Administración de Sistemas Informáticos en Red.
   * Armarios rack 42U reales, switches gestionados Cisco Catalyst, VLANs, routing OSPF, cortafuegos pfSense, cableado estructurado Cat6A/Fibra y virtualización con Proxmox y Docker.
3. **Tech Hub de Desarrollo Web y Aplicaciones (`DAW` / `DAM`)**
   * Grados Superiores en Desarrollo de Aplicaciones Web y Multiplataforma.
   * Entornos tipo startup con monitores dobles: desarrollo Frontend moderno, Backend (Node, Python, PHP), APIs REST, bases de datos SQL/NoSQL y flujo de trabajo colaborativo con Git y Scrum.

## 🌟 Características y Funcionalidades Interactivas

* **Estilo Visual Moderno**: Paleta con fondo oscuro profundo (`#0b101b`), azul institucional Somorrostro (`#0084ff`), naranja vibrante de innovación (`#ff7700`) y efectos glassmorphism.
* **Contador Interactivo en JavaScript**: Animación de métricas de impacto (*96% inserción laboral, +450 retos superados, 1.500 h prácticas en taller y +280 empresas con convenio Dual*) sincronizado con `IntersectionObserver`.
* **Fichas Técnicas Modales**: Ventanas emergentes con detalles técnicos, retos típicos y salidas laborales para cada especialidad.
* **Test de Orientación Vocacional (1 min)**: Cuestionario dinámico de 3 preguntas que diagnostica qué taller tecnológico encaja con el perfil del usuario.
* **Soporte Bilingüe Dinámico (ES / EU)**: Conmutador en tiempo real para alternar los textos principales entre castellano y euskera.
* **Formulario Interactivo**: Solicitud de visita guiada con validación y confirmación visual inmediata.

## 💻 Puesta en Marcha Local

Para clonar y levantar el servidor web localmente:

```bash
# 1. Clonar el repositorio
git clone https://github.com/asierunanue09/somo-ia.git
cd somo-ia

# 2. Iniciar el servidor web estático (requiere Node.js instalado)
node server.js
```

Abre tu navegador en:  
👉 **[http://localhost:3000](http://localhost:3000)**
