Metodología ETHAZI: Aprende Haciendo

En Somorrostro decimos adiós a los apuntes estériles memorizados para un examen. Trabajamos con el modelo ETHAZI (Eredu Berria): una dinámica colaborativa en la que adquieres competencias técnicas y habilidades humanas resolviendo casos reales propuestos por empresas.

01

El Desafío Real

Una empresa del tejido industrial de Bizkaia o el claustro plantea un reto auténtico: migrar una infraestructura a la nube, auditar una red o programar un dashboard analítico.

Planteamiento
02

Célula de Trabajo

Te integras en un equipo autónomo con roles rotativos (Project Leader, Administrador de Sistemas, Desarrollador, Tester). Se fomenta la comunicación y la empatía.

Compañerismo
03

Manos al Taller

Ensambláis hardware, configuráis switches Cisco, desplegáis contenedores Docker y escribís código en GitHub. Ensayáis, corregís errores y optimizáis.

100% Práctica
04

Defensa & Validación

El equipo presenta la solución terminada ante el cliente y el tutor. Evaluamos la solvencia técnica, la calidad del entregable y el trabajo en equipo.

Preparación Laboral

Los 3 Talleres de Informática

Tres laboratorios especializados dotados con infraestructura de nivel empresarial en los edificios formativos del campus en Muskiz.

Edificios Lanberri & Suberri • San Juan 10, Muskiz
01
Grado Medio · SMR

Taller de Montaje y Mantenimiento

Sistemas Microinformáticos, hardware y electrónica

Aprende a ensamblar estaciones de trabajo y servidores desde cero en bancos con protección electrostática (ESD). Realiza diagnósticos con polímetros y osciloscopios, sustituye procesadores y recupera sistemas.

¿Qué dominarás en este taller?

  • Ensamblaje y modding de equipos avanzados y servidores rack.
  • Diagnóstico electrónico de fuentes, placas base y memorias RAM.
  • Instalación y clonación masiva de sistemas Windows y GNU/Linux.

Equipamiento del Taller

Bancos ESD Intel / AMD Ryzen NVMe PCIe Gen5 Clonezilla / Ventoy UEFI / BIOS Mod
02
Grado Superior · ASIR

Laboratorio de Redes y Servidores

Infraestructuras críticas, switches Cisco y ciberseguridad

Administra armarios rack de 42U reales. Tira cableado estructurado Cat6A y realiza fusiones de fibra óptica. Configura switches gestionados Cisco, protocolos OSPF y cortafuegos pfSense.

¿Qué dominarás en este taller?

  • Segmentación mediante VLANs, Trunking 802.1Q y routers Cisco.
  • Fusión de enlaces de fibra óptica y certificación de cableado.
  • Virtualización empresarial con Proxmox, VMware y contenedores Docker.

Equipamiento del Taller

Cisco IOS Racks 42U Wireshark pfSense Firewall Proxmox / Docker
03
Grado Superior · DAW / DAM

Tech Hub de Desarrollo Web & Apps

Full-stack, interfaces responsivas, APIs y bases de datos

Un entorno colaborativo diseñado para simular una empresa tecnológica moderna. Programa aplicaciones SPA reactivas, diseña arquitecturas cliente-servidor en la nube y gestiona repositorios con flujos Git y metodologías ágiles Scrum.

¿Qué dominarás en este taller?

  • Frontend con JavaScript moderno, TypeScript, React y Tailwind CSS.
  • Backend con Python, PHP/Laravel, Node.js y bases de datos SQL/NoSQL.
  • Flujos de trabajo en equipo en GitHub con Pull Requests y despliegue CI/CD.

Equipamiento del Taller

JavaScript / TS React / Tailwind Python / Flask MySQL / MongoDB Git & GitHub

Pilar 01 • Cultura Somorrostro

Compañerismo Real: Aquí Nadie se Queda Atrás

En nuestras aulas no existe competencia individualista. Fomentamos el mentoring entre iguales: quien domina el montaje apoya al que aprende a programar, y viceversa. Los tutores te conocen por tu nombre y te acompañan de manera individualizada en cada reto.

Pilar 02 • Futuro Profesional

Conexión Total con Empresas y Retos Productivos

A través de nuestro servicio de empleo Lanberri y convenios con más de 280 empresas de Bizkaia (Petronor, firmas de los Parques Tecnológicos y consultoras IT), cursarás la modalidad de FP Dual remunerada combinando formación en el campus y trabajo real en empresa.
